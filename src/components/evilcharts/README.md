# Evil Charts

Source: https://github.com/legions-developer/evilcharts (MIT).
Registry: https://evilcharts.com/r/echarts-composed-chart.json, retrieved 2026-10-03.

The composed chart and its five shared modules are vendored without changing the application shell or adding shadcn dependencies. Local adaptations: relative imports, strict indexed-access compatibility, optional YAxis min/max bounds, null-preserving main line series, and pt-BR tooltip numbers. OperationalChart provides the NexaSST palette, lazy loading and an accessible data table. Keep null values disconnected and training compliance fixed at 0–100 when updating these sources.
